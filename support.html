ZeroUI isn't working?

First, try the following:
- Refresh the YouTube page
- Close all YouTube tabs and restart the browser
- Disable any other extensions that modify YouTube
- Disable and re-enable ZeroUI
- Uninstall and reinstall ZeroUI

If the problem persists, please report the issue.

To help diagnose the problem faster, include:
- Description of the issue
- Screenshot or video
- Browser and version
- ZeroUI version
